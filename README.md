## What I actually do

I build production AI agents at Laburen: prompts, tools and MCP servers on Cloudflare Workers, shipped into WhatsApp where real people use them every day. Not demos — things that break on a Sunday and have to be fixed on a Sunday.

I also built [Rulo](https://www.rulofitness.com), a fitness agent on WhatsApp. You send a voice note after your set and the workout is logged. Landing, dashboard, MCP server and middleware.

## What this repo is

A one-day build for Papasud, a 140-year-old seed potato company whose 20 years of history live in a spreadsheet. `apps-script/` reads it, `prompts/` is the WhatsApp agent that answers questions about it, `papin-mcp-server/` is where the tools were headed.
