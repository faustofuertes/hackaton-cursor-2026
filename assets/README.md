# Assets

Material provisto por Papasud para el hackathon: datos de muestra, planillas,
documentación, fotos y cualquier otro recurso de referencia.

## Organización

Un subdirectorio por tipo de recurso, con nombres sin espacios:

```
assets/
├── planillas/    # Excel, CSV, exports de Sheets
├── imagenes/     # fotos de cultivo, capturas
└── documentos/   # PDFs, normativa, plantillas
```

## Antes de agregar algo acá

Este repositorio está en GitHub. Revisar que el archivo no traiga datos que no
deberían ser públicos: nombres de clientes, precios, contactos, credenciales de
acceso. Si el recurso es sensible, va anonimizado o queda fuera del repo.
